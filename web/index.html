General

JARVIS reads out today's reminders and unread mail at this time, if its window is open. Clear the time to switch it off. You can also say "good morning" or "brief me" at any time.
It starts quietly in the system tray, near the clock.
Closing the window leaves JARVIS running in the tray, so reminders still arrive as notifications. Press Ctrl+Alt+J to bring the window back. To stop JARVIS completely, right-click its tray icon and choose Quit.

Gmail (read-only)

Not your normal password. Turn on 2-Step Verification, then create a 16-letter app password at myaccount.google.com/apppasswords. It is stored in Windows Credential Manager on this laptop only.

Google Calendar (read-only)

In Google Calendar on the web: Settings, click your calendar on the left, "Integrate calendar", copy "Secret address in iCal format". Stored in Windows Credential Manager on this laptop only.

GitHub (read-only)

A fine-grained token with read-only access. Stored in Windows Credential Manager on this laptop only.

Voice

No voices are installed in data/voices, so replies cannot be spoken.

While this is on and the window is open, the microphone stays on. Audio is checked on this laptop for the wake word and is never saved.
While JARVIS is in the tray, saying "Hey JARVIS" opens the window, which answers "Yes?" and listens. The microphone stays on whenever JARVIS is running. Audio is checked on this laptop and never saved.
